# Experiments

Measured inquiry for this repository. Read [AGENTS.md](AGENTS.md) before adding a file.

| Directory | Contains |
|---|---|
| [algorithms/](algorithms/README.md) | Algorithm writeups and notebooks |
| [planned/](planned/README.md) | Locked predictions; not yet run |
| [successes/](successes/README.md) | Predictions held past the strong bar (hypothesis supported) |
| [mixed/](mixed/README.md) | Partial signal; not a clean win, not a dead end |
| [refuted/](refuted/README.md) | Solid dead ends, or a protocol that failed |
| [results/](results/README.md) | Artifacts named after the run slug |
| [templates/](templates/README.md) | Blank forms |

A campaign in `lab/campaigns/` may coordinate several files here. The campaign `program.md` must not copy predictions.

Start a run: [cookbook — starting an experiment](../../.agents/cookbook/starting-an-experiment.md). Start a campaign: [cookbook — starting a campaign](../../.agents/cookbook/starting-a-campaign.md).
