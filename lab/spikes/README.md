# Spikes

Informal exploration. No prior hypothesis.

The agent places spike work in this directory. The agent does not invent predictions after seeing a spike outcome. Quantitative tests start as a new file under `docs/experiments/planned/`.

A spike is not a campaign. Campaigns live in [../campaigns/](../campaigns/README.md). Rules: [../AGENTS.md](../AGENTS.md).

This directory has no shipped spikes.
