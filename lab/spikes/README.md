# Spikes

Informal exploration. No prior hypothesis.

A spike gets a descriptive name of 2 to 5 words. A spike opens with a pseudocode block that states what it tries. The agent writes it before the code and keeps it accurate. Detail: [../AGENTS.md](../AGENTS.md).

The agent places spike work in this directory. The agent does not invent predictions after seeing a spike outcome. Quantitative tests start as a new file under `lab/experiments/planned/`.

A spike is not a campaign. Campaigns live in [../campaigns/](../campaigns/README.md). Rules: [../AGENTS.md](../AGENTS.md).

This directory has no shipped spikes.
