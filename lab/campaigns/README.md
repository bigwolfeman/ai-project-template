# Campaigns

A campaign is a bounded research program. It coordinates one or more experiments and many trials.

Place a live campaign in `lab/campaigns/<slug>/`. Copy `lab/templates/campaign/`. If that template is absent, the agent stops and reports the missing path. Do not use the template path as a live campaign.

This directory has no live campaigns.
