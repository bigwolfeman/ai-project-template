# Post-mortems

Incident write-ups: a bug reached a place it should not have (user, merged PR, release). The interesting part is why process let it through.

A postmortem is not an [Agent Note](../../.agents/notes/README.md) and not an [experiment failure](../experiments/AGENTS.md).

Write one when the bug is subtle, systemic, and costly to rediscover. Copy [templates/postmortem.md](templates/postmortem.md).

Open with an executive summary: what broke, root cause, why it escaped, durable lesson.
